phần 1.
- json viewer giúp hiển thị dữ liệu api dạng json rõ ràng, dễ đọc và tìm lỗi
- extension quá nhiều có thể làm trình duyệt chậm và tốn ram

phần 2. 
- json viewer: đọc dữ liệu json
- colorzilla: lấy mã màu trên website
- ublock origin lite: chặn quảng cáo độc hại
- wappalyzer: nhận diện công nghệ website
- modheader: kiểm tra và chỉnh sửa http header khi kiểm thử
- nhấn biểu tượng extensions trên chrome rồi chọn ghim để đưa tiện ích lên toolbar

phần 3.
- mở chrome extensions để tắt tiện ích không cần thiết
- mở chrome task manager bằng shift + esc để kiểm tra mức sử dụng ram của từng extension
- tắt hoặc gỡ tiện ích gây lag
- chỉ bật tiện ích cần thiết khi kiểm tra api và biểu đồ waterfall
